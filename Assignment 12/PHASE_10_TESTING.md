# Phase 10: Statistics review guide

Live page: https://jnuso.github.io/CSE-4095/#/statistics

Use a private/incognito window for an empty history, or your usual browser to inspect your existing practice. Automated checks use disposable contexts and never erase your actual progress.

1. **Empty history:** In a private window, open Statistics. Expect zero totals, 0% accuracy, all four operation cards and all four clearly labeled difficulty cards, and helpful empty-history messages.
2. **Known results:** Choose Addition, Level 1, and five questions. Mark three right and two wrong, regardless of which multiple-choice answers you selected. Open Statistics. With no earlier history, expect 5 attempted, 3 marked right, 2 marked wrong, and 60% overall. Addition and Level 1 should match; unused operations/levels should be zero.
3. **Incomplete session:** Start another session, report one answer, then use Statistics in the navigation before finishing. That answer counts immediately, and the recent session is labeled Incomplete. Refresh Statistics: totals and history remain.
4. **Different practice:** Practice a different operation and difficulty. Only the actual operations used by questions belong in their buckets; simply selecting an operation does not create an attempt. Recent sessions show dates, actual operations, level, counts, and accuracy, newest first. More than ten saved sessions exposes Show more sessions.
5. **Cancel reset:** Select Reset Statistics. Keep my history starts focused. Escape or Keep my history closes the dialog without changing data. Keyboard focus returns to Reset Statistics.
6. **Confirm reset, only if you want to erase this browser's history:** Note your setup choices and animation preference. Confirm Erase history. Expect zero totals and empty history after refresh; setup choices and animation preference remain. Unrelated browser data is not cleared. Start a fresh session after reset; practice sessions already open before reset cannot restore erased history.
7. **Phone and keyboard:** Open the same URL on your phone; cards should stack and buttons remain usable without horizontal scrolling. Tab through navigation and reset controls. Progress is separate on each browser/device.

Statistics cover the newest 100 retained sessions on this browser, including unfinished sessions. Percentages round to whole numbers and use the child's self-report, not whether the selected choice was mathematically correct. These are saved-history totals, not an unlimited lifetime archive. Mistake-pattern statistics and settings controls belong to later phases.

From math-practice-app, run `npm.cmd run check:all` for formatting, lint, unit/component checks, type checking, both builds, regression/accessibility browser tests, and Pages hosting checks. See TESTING.md for reports and isolation details. Actual results and review limitations are recorded in DEVELOPMENT_LOG.md.
