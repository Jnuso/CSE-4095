# Phase 11: Settings review guide

Live page: https://jnuso.github.io/CSE-4095/#/settings

Use a private/incognito window to test from a clean start without erasing the progress in your usual browser. Automated tests use their own browser contexts and never clear your profile.

1. **Initial preferences:** Open Settings. Sound effects should be off; card animation and explanations should be on. Defaults are Addition, Beginner, and 10 questions. The mastery threshold belongs to a later phase and has no control here yet.
2. **Explicit save and validation:** Choose Division, Advanced, and 5 questions. Turn animation and explanations off, then select Save Settings. Expect a saved confirmation. Refresh and confirm the choices remain. Clearing every operation should disable Save Settings and explain why; choosing an operation enables it again. Changes are not saved until you select Save Settings.
3. **Use defaults and override one session:** Open Practice from navigation. It should load your saved Division/Advanced/5-question defaults. Change this session to Beginner, then start. The session should use Beginner. Open Practice again from navigation: the saved default should still be Advanced. Edit choices/Practice Again on a recap can intentionally carry the prior session's configuration; those links also do not replace saved defaults.
4. **Actual preferences:** With explanations off, flip a card: its answer remains visible, but the short explanation is absent. Turn explanations on in Settings, save, and start another session. The revealed answer should include a short arithmetic explanation. Animation off removes the flip motion; reduced-motion devices stay still even with animation on. Turn sound on and save, then flip a card to hear a gentle tone. Turn it off and save to silence subsequent flips. Audible quality, device volume, and browser audio permissions require a human check; automated tests do not prove that a sound was heard.
5. **Preserve progress:** Report an answer and visit Settings. Saving preferences should not erase Statistics or session history. Refresh to check persistence.
6. **Cancel clearing:** Select Clear All Application Data. Keep my data starts focused. Escape or Keep my data must close the dialog without changing preferences or history, and keyboard focus returns to the clear button.
7. **Confirm clearing, only in a browser where you want to erase the app's data:** Select Erase all app data. Expect Home, empty Statistics, and the original preferences/defaults when you reopen Settings. Refresh to confirm. Unrelated browser data remains. Start fresh sessions in any other open tabs afterward; old sessions cannot restore erased history. Clear All also removes any extra mistake-pattern fields in the app's saved envelope, although mistake tracking itself is a future phase.
8. **Phone and keyboard:** Check that options, Save Settings, and the confirmation dialog fit and are reachable without horizontal scrolling. Navigate controls with Tab/Space and cancel the dialog with Escape.

Statistics reset keeps preferences. Clear All Application Data restores preferences as well as erasing practice history. Both are limited to the app's saved data on this browser/device; they do not synchronize other devices. If saving or clearing fails, the app must show a clear message and must not claim that the write succeeded. Clear All can deliberately recover unreadable/unsupported app data after explicit confirmation; ordinary saves continue protecting it.

From math-practice-app, run `npm.cmd run check:all`. This includes unit/component, browser/accessibility, real browser restart, normal build, and strict Pages hosting checks. TESTING.md explains reports; DEVELOPMENT_LOG.md records actual verification and review results. TODO items are checked only after the full gate passes.

To repeat the focused hosted check from the course repository root, run `node "Assignment 12/notes/phase-11-live-check.mjs"`. It uses disposable desktop/mobile data and saves ignored screenshots/results under math-practice-app/output/playwright/phase-11-live. This complements the full local gate; it does not test your saved profile or prove audible sound quality.
