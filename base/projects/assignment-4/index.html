ASSIGNMENT 04 / 07

Card Game 24.

Four cards. One target. Build an arithmetic expression equal to 24, then see whether the game’s solver can find another route.

Game logicExpression validationPlayable demo
01 / THE CHALLENGE

Make 24 from four cards

The page deals four card values and lets you combine them with addition, subtraction, multiplication, division, and parentheses. Every value must be used exactly once. It checks both the arithmetic and whether your expression uses the dealt hand.

The project also includes a solver that explores number orders, operators, and parenthesized groupings to find a solution when one exists.

Play Card Game 24 ↗
02 / WHAT TO TRY

A classic tricky hand

For the values 3, 3, 8, and 8, one solution is 8 / (3 - 8 / 3) = 24. Generate a new hand in the demo and try to solve it before showing the answer.
