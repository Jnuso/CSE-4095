ASSIGNMENT 05 / 07

8-Puzzle Search.

Two search strategies tackle the same sliding-tile puzzle. Follow their optimal solution paths and compare how much work each one does.

Breadth-first searchA* searchInteractive visualization
01 / THE COMPARISON

Same path length, different effort

Breadth-first search (BFS) expands states by distance from the start. A* uses Manhattan distance to prioritize states that seem closer to the goal. The assignment includes separate browser visualizers and Python solvers for both methods.

From the required starting board, both found an optimal 30-move solution. The recorded comparison shows that A* expanded far fewer states.

02 / WHAT TO NOTICE

Watch the frontier

Both demos let you select steps in the solution path. The A* page also shows each state’s path cost g(n), estimated remaining cost h(n), and priority f(n), plus candidate states waiting to be explored.
