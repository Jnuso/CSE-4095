ASSIGNMENT 03 / 07

Benford’s Law Experiments.

Do the leading digits of number sequences follow a predictable pattern? This Python project compares observed frequencies with Benford’s Law.

PythonMathematical patternsData analysis
01 / THE QUESTION

Why does 1 appear first so often?

Benford’s Law predicts that lower digits occur more often as the first digit of many datasets. The program measures leading digits in Fibonacci numbers, powers of 2, factorials, and an original powers-of-3 experiment. It compares their frequencies with the predicted distribution.

The program can also export a dependency-free SVG chart for any experiment. For very large sequences, it uses logarithms to avoid constructing huge integers.
