CODEX:
A **baseline is the performance of a simple prediction strategy**. It gives us a starting point for judging whether our more sophisticated models are useful.

For this classification assignment, the strategy is **always predict the most common training class**. We aren’t averaging exam scores or feature values.

For example, suppose a training set contains:

- 60% `No`
- 40% `Yes`

The baseline learns that `No` is more common and predicts **`No` for every student**. If a validation set also contains 60% `No`, that strategy achieves **60% accuracy**, even though it ignores all the students’ habits.

We’ll obtain our baseline score using five-fold cross-validation:

1. Use four folds to determine the most common class.
2. Predict that class for every student in the remaining validation fold.
3. Calculate validation accuracy.
4. Repeat until each fold has served as validation data.

**The average comes afterward:** we average those five accuracy scores to report the **mean baseline CV accuracy**. We also calculate their standard deviation to describe how much performance varies between folds.

So there are two separate things: **the baseline’s prediction rule is “choose the majority class”; its reported score is the average accuracy across folds.**

An average *can* be a prediction baseline for regression—for example, always predicting the mean training exam score. Here, our target is Yes/No, so we use the majority class instead.

For **Part 4**, we define how numerical and categorical features will be prepared:

```python
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline

numerical_features = [
    "study_hours_per_week",
    "sleep_hours_per_night",
    "attendance_rate",
    "practice_problems_per_week",
    "commute_minutes",
]

categorical_features = [
    "prior_programming_experience",
    "study_group",
]

numerical_pipeline = Pipeline([
    ("imputer", SimpleImputer(strategy="median")),
    ("scaler", StandardScaler()),
])

categorical_pipeline = Pipeline([
    ("imputer", SimpleImputer(strategy="most_frequent")),
    ("encoder", OneHotEncoder(handle_unknown="ignore")),
])

preprocessor = ColumnTransformer([
    ("numerical", numerical_pipeline, numerical_features),
    ("categorical", categorical_pipeline, categorical_features),
])
```

Here’s what each piece does:

- **Numerical imputer:** replaces missing values with that column’s training median. The median is less influenced by extreme values than the mean.
- **StandardScaler:** centers numerical features around zero and scales them using their training standard deviations.
- **Categorical imputer:** replaces missing categories with the most common training category.
- **OneHotEncoder:** creates numerical indicator columns for categories. `handle_unknown="ignore"` lets it handle a validation category that was absent during training.
- **ColumnTransformer:** sends each group of columns through its corresponding preprocessing steps.

These objects define the procedure. During cross-validation, the pipeline learns the medians, scaling values, and categories separately from each fold’s training portion.

For **Part 5**, we create and evaluate the majority-class baseline:

```python
from sklearn.dummy import DummyClassifier
from sklearn.model_selection import StratifiedKFold, cross_val_score

cv = StratifiedKFold(
    n_splits=5,
    shuffle=True,
    random_state=42,
)

baseline_model = Pipeline([
    ("preprocessor", preprocessor),
    ("classifier", DummyClassifier(strategy="most_frequent")),
])

baseline_cv_scores = cross_val_score(
    baseline_model,
    X_train,
    y_train,
    cv=cv,
    scoring="accuracy",
)

baseline_summary = pd.DataFrame({
    "Mean CV accuracy": [baseline_cv_scores.mean()],
    "Std. accuracy": [baseline_cv_scores.std()],
}, index=["Majority baseline"])

display(baseline_summary.round(3))
```

**`StratifiedKFold`** divides the training data into five folds while preserving approximately the same class proportions. Shuffling with `random_state=42` makes those folds reproducible. We’ll reuse `cv` for later model comparisons.

**`DummyClassifier`** always predicts the most common class from its training portion. Its prediction rule ignores feature values; attaching preprocessing gives it the same pipeline structure we’ll use for the other models.

**`cross_val_score`** trains and validates the pipeline five times, returning five validation accuracy scores. It uses only the training data we pass into it.

Finally, **`.mean()`** averages those scores, while **`.std()`** measures their variation. The proposed code produces:

| Model | Mean CV accuracy | Standard deviation |
|---|---:|---:|
| Majority baseline | 0.605 | 0.010 |

That means **60.5% average accuracy**, with a standard deviation of **1 percentage point**. The individual fold accuracies are **62.5%, 60%, 60%, 60%, and 60%**.
