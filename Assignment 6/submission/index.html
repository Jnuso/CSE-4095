What do these statistics mean?

The table contains 625 possible four-hand combinations at each level and 21 levels from 0 through 20. It is built once when the page loads. “Legal branches” is the number of attacks and redistributions available from the current node; A chooses the maximum score and B chooses the minimum.

Bottom-up DP vs plain recursion

Both methods will score the same opening at a small depth. Plain recursion revisits positions; bottom-up DP stores each state and level once. Timings also depend on the device.

i

A quick reminder

A tap adds fingers to the target hand. Five or more knocks it out. Lose both hands and you lose; if both players survive 20 moves, the score is a tie.
